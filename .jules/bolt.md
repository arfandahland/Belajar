## 2026-06-08 - Optimizing Re-renders in Builder Applications
**Learning:** In applications where a large state object is managed at a high level (like a landing page builder), updating a single field in the Sidebar triggers a re-render of the entire preview area. React.memo is highly effective here as the preview sections are often independent and receive distinct subsets of the state. Additionally, `import * as Icons` from `lucide-react` is a common anti-pattern that bloats bundles by preventing tree-shaking; using a static map with named imports preserves dynamic selection while optimizing size.
**Action:** Always check for centralized state re-render patterns in editor/builder UIs. Prefer named imports and static maps for icon libraries to ensure optimal tree-shaking.
